Política de Privacidade — Granix - Controle de Gastos

Última atualização: 26 de março de 2026

1. Introdução

O Granix - Controle de Gastos é desenvolvido por Torlaco Systems. Esta política descreve como tratamos as informações dos usuários do app.

2. Dados coletados

O Granix não coleta, transmite nem armazena dados pessoais em servidores externos. Todos os dados financeiros inseridos pelo usuário (gastos, receitas, formas de pagamento, pessoas e categorias) são armazenados exclusivamente no dispositivo local.

3. Armazenamento local

Os dados são salvos localmente no dispositivo usando banco de dados Hive e SharedPreferences. Nenhuma informação é enviada para a internet ou compartilhada com terceiros.

4. Backup

O usuário pode exportar e importar seus dados manualmente via arquivo JSON, salvo na pasta Downloads do dispositivo. Este arquivo fica sob total controle do usuário.

5. Exportação de relatórios

O app permite exportar relatórios em PDF e CSV salvos localmente na pasta Downloads. Nenhum dado é enviado para serviços externos.

6. Autenticação biométrica

O app pode utilizar a impressão digital do dispositivo para proteger o acesso. Esses dados biométricos são processados exclusivamente pelo sistema operacional Android e nunca são acessados ou armazenados pelo app.

7. Assinatura

O app oferece período de teste gratuito e assinatura mensal processada pelo Google Play Billing. As informações de pagamento são gerenciadas exclusivamente pelo Google e não são acessadas pelo app.
